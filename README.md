# Portfolio

A simple two-page portfolio: a home page and a filterable projects page. No build step.

## Files

- `index.html` – home
- `projects.html` – project cards 
- `style.css` – all styling, with light and dark themes
- `main.js` – theme toggle and project rendering

## Customise

1. Replace "Your Name", `you@example.com` and the GitHub/LinkedIn links in both HTML files.
2. Edit the `projects` array in `projects.html`. Use `image: "images/shot.png"` instead of `emoji` for a real screenshot.
3. Change the accent colour via `--accent` in `style.css`.

## Publish on GitHub Pages

1. Create a repo (name it `your-username.github.io` for a root URL, or any name for a project URL).
2. Put these files in the repo root and push to `main`.
3. In the repo go to **Settings → Pages**, set **Source** to "Deploy from a branch", choose `main` and `/ (root)`, then Save.
4. After a minute the site is live at `https://your-username.github.io/` (or `/repo-name/`).
